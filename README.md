# فروشگاه امیر — نسخه GitHub Pages + Google Sheets

این نسخه سایت را کاملاً استاتیک و روی GitHub Pages نگه می‌دارد، ولی به‌جای `localStorage` مرورگر یا فایل JSON دستی، از یک **Google Sheet واقعی** به‌عنوان دیتابیس استفاده می‌کند — از طریق یک اسکریپت رابط به نام Google Apps Script.

## ساختار پروژه
```
apps-script/
  Code.gs              کد بک‌اند — این را روی GitHub آپلود نکن! فقط داخل
                        ویرایشگر Apps Script (متصل به گوگل‌شیت) قرار می‌گیرد.

site/                   ← فقط محتوای این پوشه را روی GitHub آپلود کن
  index.html            صفحه اصلی فروشگاه
  admin.html            صفحه ورود مدیر
  admin-panel.html      پنل مدیریت محصولات
  css/style.css
  js/
    api.js              آدرس Apps Script را اینجا وارد می‌کنی
    store.js            نمایش محصولات در صفحه اصلی
    admin.js            منطق ورود و مدیریت محصولات
  robots.txt, sitemap.xml
```

## چطور کار می‌کند؟
1. یک Google Sheet می‌سازی با یک شیت به نام `Products`.
2. کد `Code.gs` را به همان شیت وصل و به‌صورت «Web App» منتشر (Deploy) می‌کنی — گوگل یک آدرس اینترنتی به تو می‌دهد.
3. سایت گیت‌هابت (کاملاً استاتیک) با جاوااسکریپت به آن آدرس وصل می‌شود: صفحه اصلی محصولات را می‌خواند، و پنل مدیریت می‌تواند اضافه/ویرایش/حذف کند.
4. هر تغییری که در پنل انجام بدی مستقیم در همان Google Sheet ذخیره می‌شود — می‌توانی حتی خودِ شیت را هم دستی باز کنی و ردیف‌ها را ببینی.

## مرحله ۱ — ساخت گوگل‌شیت
1. یک Google Sheet جدید بساز (sheets.google.com → Blank).
2. نام شیت پایین صفحه (تب پیش‌فرض `Sheet1`) را به `Products` تغییر بده.
3. در سطر اول این هدرها را دقیقاً به همین ترتیب بنویس:
   ```
   id | name | category | price | description | image | inStock | createdAt
   ```

## مرحله ۲ — اتصال Apps Script
1. از منوی بالای شیت: **Extensions → Apps Script**.
2. کل محتوای فایل `apps-script/Code.gs` (که برایت فرستادم) را کپی کن و به‌جای کد پیش‌فرض (`function myFunction() {}`) در ویرایشگر Apps Script جای‌گذاری کن.
3. از بالای صفحه، روی منوی کشویی توابع، تابع `setupAdmin` را انتخاب کن و دکمه **Run** را بزن.
4. اولین بار گوگل از تو مجوز (Authorize) می‌خواهد — چون این اسکریپت فقط مال خودت است، اجازه بده (روی حساب گوگل خودت، Advanced → Go to project (unsafe) اگر پیام هشدار دید، طبیعی است چون اسکریپت شخصی توییده و توسط گوگل تأیید نشده).
5. بعد از اجرای موفق `setupAdmin`، کاربر مدیر (نام کاربری `Amir` و رمز `admin`) ساخته می‌شود.

## مرحله ۳ — انتشار (Deploy) به‌عنوان Web App
1. در ویرایشگر Apps Script: **Deploy → New deployment**.
2. کنار «Select type» چرخ‌دنده را بزن و **Web app** را انتخاب کن.
3. تنظیمات:
   - Execute as: **Me**
   - Who has access: **Anyone**
4. **Deploy** را بزن. گوگل یک آدرس شبیه این می‌دهد:
   ```
   https://script.google.com/macros/s/XXXXXXXXXXXXXXXXX/exec
   ```
5. این آدرس را کپی کن — همینی است که در مرحله بعد لازم داری.

⚠️ هر بار که کد `Code.gs` را تغییر بدهی، باید دوباره **Deploy → Manage deployments → ویرایش (مداد) → Version: New version → Deploy** کنی تا تغییرات روی آدرس منتشرشده اعمال شود.

## مرحله ۴ — وصل کردن سایت به آدرس Apps Script
فایل `site/js/api.js` را باز کن و خط زیر را با آدرس واقعی مرحله قبل جایگزین کن:
```js
const API_URL = "https://script.google.com/macros/s/XXXXXXXXXXXXXXXXX/exec";
```

## مرحله ۵ — آپلود روی GitHub Pages
1. یک ریپازیتوری جدید بساز (مثلاً `amir-shop`).
2. فقط **محتوای پوشه `site/`** را در ریشه‌ی ریپازیتوری آپلود/کامیت کن (نه پوشه `apps-script/` — آن باید فقط داخل Apps Script بماند و هرگز به گیت‌هاب نرود).
3. برو به Settings → Pages → از Source شاخه اصلی (`main`) را انتخاب کن.
4. بعد از چند دقیقه سایتت روی آدرسی شبیه `https://USERNAME.github.io/amir-shop/` بالا می‌آید.
5. آدرس واقعی را در `index.html`، `robots.txt` و `sitemap.xml` به‌جای `REPLACE-WITH-YOUR-USERNAME` و `REPLACE-WITH-REPO-NAME` جایگزین کن.

## ورود مدیر
- آدرس: `admin.html`
- نام کاربری: `Amir`
- رمز عبور: `admin`

برای تغییر رمز: در `Code.gs` مقدار `PASSWORD` داخل تابع `setupAdmin` را عوض کن، دوباره فقط همان تابع را از ویرایشگر Apps Script اجرا کن (نیازی به Deploy مجدد نیست، چون این تغییر روی داده است نه روی کد در دسترس عموم).

## چرا این نسخه امن است
- **کد بک‌اند (`Code.gs`) هرگز وارد گیت‌هاب نمی‌شود** — فقط داخل حساب گوگل شخصی تو زندگی می‌کند. فقط یک آدرس عمومی (Web App URL) از آن بیرون می‌آید که فقط اجازه‌ی خواندن محصولات و ورود با رمز درست را می‌دهد.
- رمز عبور به‌صورت هش (SHA-256 با نمک/salt تصادفی) در Script Properties ذخیره می‌شود، نه به‌صورت متن ساده در جایی قابل‌مشاهده.
- عملیات نوشتن (افزودن/ویرایش/حذف) فقط با یک توکن معتبر ممکن است که تنها بعد از ورود موفق صادر می‌شود و بعد از ۲ ساعت منقضی می‌شود.

## محدودیت‌ها (صادقانه بگویم)
- **سهمیه رایگان گوگل:** Apps Script برای حساب‌های شخصی گوگل سقف مصرف روزانه دارد (برای یک فروشگاه کوچک با ترافیک معمولی کاملاً کافی است).
- **تأخیر:** پاسخ Apps Script معمولاً کمی کندتر از یک دیتابیس اختصاصی (مثل MySQL روی InfinityFree) است، چون هر درخواست باید گوگل‌شیت را باز/بخواند.
- اگر یک روز به آدرس Web App دسترسی نداشته باشی (مثلاً اگر Deploy را دستکاری کنی)، سایت محصولات را نشان نمی‌دهد تا دوباره درستش کنی.
- برای فروشگاه‌های بزرگ‌تر با ترافیک بالا، دیتابیس اختصاصی (نسخه InfinityFree) گزینه پایدارتری است.

## تست‌هایی که قبل از تحویل انجام دادم
منطق هش رمز عبور، ورود صحیح/غلط، افزودن/ویرایش/حذف محصول، رد کردن توکن نامعتبر، و رندر شدن صفحه اصلی و پنل مدیریت را با یک سرور شبیه‌ساز کامل تست کردم — همه‌چیز مطابق انتظار کار می‌کند. تنها بخشی که در این محیط قابل تست نبود، رفتار واقعی زیرساخت Google Apps Script (سرعت، سهمیه، رفتار CORS واقعی) است — این‌ها را باید بعد از Deploy واقعی روی حساب گوگل خودت ببینی.
